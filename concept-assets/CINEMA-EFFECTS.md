# 電影風入口互動

電影風新版已成為正式入口 `index.html`。先前入口完整保留為 `old.html`；`index-concept-cinema.html` 會轉往正式入口，舊預覽連結仍可使用。

## 六組效果

- 深度鏡頭：WebGL 1 自訂 shader，依三張照片各自的手工灰階 SVG 深度遮罩，產生小幅 2.5D 位移與慢速拉遠。遮罩是藝術化深度估計，不是真實 3D 重建；沒有替照片添加不存在的景物。
- 取景器：原生游標持續保留，外框只作附加裝飾，絕不隱藏或取代游標；照片區、連結、按鈕採不同狀態，閱讀區退去外框，保留文字游標。外框以時間基準緩動，鍵盤操作與觸控不需要它。
- 光學換景：方向性溶接、短暫失焦及暖光曝光；保留 HTML 圖片淡入作備援。連續點擊序列化，最後要求的旅程優先。
- 相紙：照片框小角度透視、方向性陰影、照片內層反光；紙框不發光，標題保留短鉛筆底線。
- 捲動敘事：保留原生捲動；首幕微拉遠、標題移出、明信片桌景輕微落定，不鎖頁、不強制停留。
- 旅程索引：小型下拉展開、分列入場、小圖顯影與手繪編號圈選。八張 192px 縮圖來自原本的旅程照片，非新生成圖片。

## 備援與效能

- 動態開關不寫入瀏覽器儲存空間；每次載入遵循系統 `prefers-reduced-motion`。
- 觸控裝置不建立 WebGL 場景或自訂滑鼠，保留照片淡入與輕量索引。
- WebGL 不可用、初始化失敗或 context 遺失，回到原始 HTML 照片，旅程連結照常工作。
- 渲染尺寸最高 220 萬像素、DPR 上限 1.5；靜止緩推約 30fps，互動時允許更高更新率。
- 首幕離開視窗、分頁隱藏時不持續繪製；緩推結束且指標穩定後停止動畫循環。
- 圖片與文字仍是 HTML，canvas、取景器及光效皆為無語意裝飾層。

## 手動驗收

1. 桌機在首幕移動滑鼠，確認建築／前景微視差、四角取景框。
2. 切冰島、芭達雅、東京；快速重複選擇，確認最終照片、文字與連結一致。三幕是首頁精選，章節編號仍對應完整八站目錄。
3. 開啟旅程目錄，確認八站順序、小圖、Escape 關閉及焦點返回。
4. 捲至旅程選輯，移到照片兩側觀察相紙反光、角度與陰影。
5. 關閉動態，再切換旅程；確認仍正常操作。
6. 測試手機與系統減少動態設定，確認無水平溢出、不啟動隱藏 GPU 工作。
